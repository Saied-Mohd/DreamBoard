# Dream Board

Your lessons, dreams, and decks, carried between the realms.

This folder is a complete, installable web app. It contains **no personal data**: your lessons, dreams, readings, and keys live only on the device you use it on.

## Put it on GitHub Pages

1. Create a new repository on GitHub (for example `dream-board`).
2. Upload everything in this folder to it, including the hidden `.nojekyll` file.
3. In the repository, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
4. After a minute your app is live at `https://<your-username>.github.io/dream-board/`.

## First time on your phone

1. Open the link in Safari (iPhone) or Chrome (Android).
2. Add it to your home screen: **Share → Add to Home Screen** on iPhone, or the **Install app** prompt on Android.
3. Open Dream Board from the home screen icon.
4. Scroll to the bottom and tap **Import a backup** to bring in your lessons, dreams, cards, and readings.
5. Tap **Settings**, paste your OpenRouter key, and tap **Test connection**.

## Keep your words safe

- Your data is saved in the app on that one device. It does not sync between devices.
- Tap **Save a backup** at the bottom now and then, and keep the file somewhere safe.
- On iPhone, use the home screen app. Safari can clear storage for websites you haven't visited in a while, but home screen apps keep theirs.

## Notes

- GitHub Pages sites are public. That's fine here, because this file holds no personal data. Never upload a backup file or an "offline copy" to the repository, since those contain your words.
- Your OpenRouter key is stored only on your device and is never part of backups.
